# Hatnikotni Chat

Standalone WordPress plugin for WhatsApp contact routing, interaction analytics, campaign attribution, and optional integrations.

## Project status

Early development. Architecture is being finalized before feature implementation.

## V1 scope

- Floating WhatsApp button
- Shortcode: [hatnikotni_chat]
- Contacts
- Direct, random, and round-robin routing
- WhatsApp click analytics
- UTM campaign attribution
- Optional integration foundation for Webhook and WooCommerce

## Design principles

- Lightweight runtime
- No external service dependency for core functionality
- Privacy-conscious first-party analytics
- WordPress-native APIs and hooks
- Secure, accessible, cache-friendly frontend
- Backward-compatible database migrations
- GitHub-managed source and release history
